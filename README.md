# QQInspector — QQ 群/用户数据检查插件

> 基于 AstrBot 框架的 QQ 群信息和用户信息查询工具。  
> 使用 SQLite 本地缓存，减少对 QQ API 的频繁调用，支持群重合度分析（推测小号）。

## 功能

| 命令 | 别名 | 说明 |
|---|---|---|
| `查询群信息 [群号]` | `group_info`, `gi` | 查看群基本信息、成员统计数据、特殊头衔列表 |
| `查询个人信息 [QQ] [群号/all]` | `user_info`, `ui` | 查看用户 QQ 资料、在指定群内的详细信息、群重合度分析 |
| `刷新查询数据` | — | 手动全量拉取所有群及成员数据到本地缓存 |

## 工作原理

### 缓存机制

```
用户查询 → SQLite 缓存中有数据？
  ├─ 是 → 直接返回缓存数据（零 QQ API 调用）
  └─ 否 → 从 QQ API 拉取 → 写入 SQLite 缓存 → 提示"请再次查询"
```

- **第一次查询**某个群或用户时，会自动从 QQ 拉取数据并缓存，然后提示你再次查询
- **后续查询**直接从本地 SQLite 读取，速度极快，不消耗 API 配额
- 使用 `刷新查询数据` 命令可全量更新所有缓存

### 缓存存储

所有数据存储在 SQLite 单文件 `cache.db` 中，位置：

```
{AstrBot数据目录}/plugin_data/QQInspector/cache.db
```

- 使用 `WAL` 模式，读写互不阻塞
- 按需读取，不将全部数据加载到内存
- 插件热重载安全，无锁冲突

## 使用方法

### 查询群信息

```
查询群信息        # 获取当前群的信息（需在群聊中使用）
查询群信息 123456 # 获取指定群的信息
gi 123456         # 同上（别名）
```

**返回内容（合并转发）：**

```

├── 群名称、群号

└── 所有拥有特殊头衔的成员列表
```


适合在首次使用或数据过期后执行。

## 重合度分析（小号检测）

### 原理

```
重合度(A, B) = |A所在的群 ∩ B所在的群| / |A所在的群|
```

- **重合度 = 100%**：B 和 A 在完全相同的群中 → 极有可能是同一个人
- **重合度 > 60%**：高度可疑，有很大关联
- **重合度 < 30%**：偶然同群，关联性较低

### 实现方式

1. 从反向索引 `user_groups:{QQ}` 获取该用户所在的所有群
2. 遍历每个群的成员，统计每个 QQ 出现的群次数
3. 计算重合度并排序，取 Top 10

> 注意：重合度分析依赖缓存的群成员数据，需先执行 `刷新查询数据`。

## 技术细节

### 数据索引

| 索引类型 | Key 格式 | 说明 |
|---|---|---|
| 正向索引 | `group_members:{gid}` | 群成员完整信息列表 |
| 正向索引 | `group_info:{gid}` | 群基本信息 |
| 反向索引 | `user_groups:{qq}` | QQ 号所在的所有群 ID 集合 |
| 用户资料 | `stranger_info:{qq}` | QQ 用户个人信息 |
| 群列表 | `group_list` | 机器人加入的所有群列表 |

### 成员排序

在群信息中，成员按以下优先级排序：
1. 群主（owner）
2. 管理员（admin）
3. 普通成员（member）
